# Библиотека промпт-шаблонов EquipmentManager

Замените заполнители в фигурных скобках своими данными и передайте выбранный шаблон целиком. Примеры показывают значения заполнителей; содержимое упомянутых файлов необходимо приложить к запросу. Примеры новых возможностей и ошибок — сценарии задач, а не утверждения о наличии дефектов в проекте.

Все шаблоны подчиняются `AGENTS.md`: объяснения и XML-комментарии на русском; C# и Blazor на .NET 9; PascalCase для классов и публичных свойств, camelCase для локальных переменных; nullable reference type safety. Сохраняй структуру проекта, меняй только относящиеся к задаче файлы, не устанавливай пакеты без согласования, не зашивай пароли и API-ключи, не игнорируй исключения. Выдавай компилируемый код и перечисляй изменённые файлы. Не заявляй об успешной сборке или тестах без фактического запуска.
