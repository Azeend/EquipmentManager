## Подтверждение требований

- Успешные ответы 200, 201 и 204 проверяются `Crud_ReturnsExpectedResponses`.
- 400 и дубликат номера 409 — `Development_InvalidAndDuplicateRequests_Return400And409`. Проверяются другой регистр и крайние пробелы, отклонение некорректных данных без изменения сохранённых записей.
- 401 — `Anonymous_Returns401`, `InvalidJwt_Returns401`, `Api_AnonymousRead_Returns401`; 403 — `NonEngineer_Write_Returns403`, `FaultApi_RejectsForbiddenRole` и проверки профиля.
- 500 — `ApiFailure_IsSafeAndCorrelated` для ошибки БД и неожиданного исключения; ответ и журнал сопоставляются по TraceId без исходных секретных данных.
- Регистрация → начало работ → завершение → чтение одной связанной записи истории — `RestApi_EquipmentFaultHistory_RoundTrip`. Проверяются автор из проверенного principal, конфликт версии и запрет удаления связанного оборудования.
- Отдельно запрет удаления оборудования с историей и сохранение этой истории проверяет `EquipmentWithHistory_Delete_Returns409AndPreservesHistory`.
- PostgreSQL-завершение без дополнительного INSERT истории, ошибка триггера и конфликт версии проверяются `FaultCompletion_DoesNotInsertDuplicateHistory`, `FaultCompletion_PropagatesTriggerFailure`, `FaultChange_RejectsStaleVersion`.

Ошибок, требующих изменения кода по шагу 8, не обнаружено. Реализация, тесты и бизнес-правила оставлены без изменений; новые механизмы не добавлялись.
