Под вариантом «без системных правил» в этом отчёте понимается отсутствие `AGENTS.md`, а не отсутствие базовых инструкций среды. ## Исходный одинаковый промпт

```text
Создай на C# метод ValidateInventoryNumber, который принимает строку с инвентарным номером оборудования и возвращает true, если номер не пустой и содержит не менее 5 символов.

Покажи код метода и кратко объясни его работу.

Это эксперимент по генерации кода. Не создавай и не изменяй файлы проекта. Не запускай сборку.
```

## Исходный ответ без AGENTS.md (полностью)

```csharp
public static bool ValidateInventoryNumber(string? inventoryNumber)
{
    return !string.IsNullOrWhiteSpace(inventoryNumber)
        && inventoryNumber.Length >= 5;
}
```

Метод возвращает `true`, если строка не равна `null`, не пустая, не состоит только из пробелов и содержит не менее 5 символов. Иначе возвращает `false`.

## Исходный ответ с AGENTS.md (полностью)

```csharp
/// <summary>
/// Проверяет, что инвентарный номер не пустой и содержит не менее 5 символов.
/// </summary>
/// <param name="inventoryNumber">Инвентарный номер оборудования.</param>
/// <returns>True, если номер соответствует требованиям; иначе false.</returns>
public static bool ValidateInventoryNumber(string? inventoryNumber)
{
    return !string.IsNullOrWhiteSpace(inventoryNumber)
        && inventoryNumber.Length >= 5;
}
```

Метод возвращает `false` для `null`, пустой строки и строки из одних пробелов. Для остальных строк возвращает `true`, если длина составляет не менее 5 символов. Пробелы в длине учитываются.
