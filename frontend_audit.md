# Аудит Frontend EquipmentManager

Дата: 16.10.2026. Приложение: .NET 9, Blazor InteractiveServer.

## Методика и границы

Изучены AGENTS.md, technical_specification.md (в частности UI-05, UI-06, UI-07), user_stories.md (US-01–US-06), Razor-компоненты, CSS оболочки и wwwroot/app.css, сервисы, валидатор и существующие тесты. Новые пакеты не добавлялись.

Браузерные проверки выполнены в Codex In-app Browser на локальном http://localhost:5156, в отдельном запущенном для аудита процессе с данными в памяти. Использованы размеры viewport 375×900, 768×900 и 1440×900 CSS px. Проверялись DOM, размеры областей и клавиатурные действия; дополнительно просмотрен снимок страницы истории на 375 px. Это не проверка всех браузеров и не сертификация доступности экранным диктором.

При автоматизированном заполнении Blazor InputText операция fill не обеспечила фиксацию значений в модели. Проверка дубликата повторена последовательным клавиатурным вводом с Tab и подтвердила ожидаемый отказ. Это ограничение способа автоматизации не трактовалось как дефект приложения.

## Оставшиеся ограничения относительно полного ТЗ

Ошибки оборудования показываются общей сводкой, без привязки каждой ошибки к полю и автоматического фокуса первой ошибки (AC-03.2 / раздел 7 ТЗ выполнены не полностью). Фильтры состояния/подразделения и счётчик результатов отсутствуют. Это существующие функциональные пробелы; в минимальное исправление трёх подтверждённых дефектов не включались. Ошибки загрузки реестра и очереди не имитировались. Реальные права и постоянное хранение не реализованы; интерфейс не выдаёт демонстрационные роли за действительную авторизацию.
